# SCARYENGINE
*я не знаю в чем его смысл но я его написал за 20 минут. упрощает писание консольных игр/прог*


Документация по функциям (API)

| Функция | Описание | Дисклеймер |
| :--- | :--- | :--- |
| `SCARYENGINE()` | Конструктор. Очищает экран и показывает логотип движка на 2 секунды. | Просто плашка, лол. |
| `clear()` | Очищает экран через ANSI-последовательность `\033[2J\033[H`. | Не рекомендуется для древнего `cmd.exe`. |
| `sleep_for(int ms)` | Аналог функции из WinAPI `Sleep()`. Замораживает поток на `ms` миллисекунд. | Ну, почти аналог. |
| `make_call(int count, int ms, std::string text);` | Имитирует входящий звонок. Принимает число звонков, задержку и текст (н-р: `*Calling!*`). | Скримеры делать самое то. |
| `print_ascii_pointer(const char* splash)` | Быстрый побайтовый вывод строк через указатели. | **Рекомендуется** для огромных логотипов (быстрее на пару миллисекунд!). |
| `print_ascii(const std::string& splash)` | Обычный вывод строки через `std::cout`. | Не рекомендуется для огромных артов. |
| `play_dialog(const vector<Line>& dg)` | Построчно крутит вектор реплик с заданной задержкой для каждой строки. | Основа сюжета. |
| `Random(int min, int max)` | Старый добрый рандомизатор на базе `mt19937`. Возвращает число `ОТ` и `ДО`. | Для шанса скримера или крита. |
| `type_text(string_view text, int delay)` | Эффект «печатной машинки». Медленно принтит текст с задержкой между буквами. | Создает атмосферу. |
| `void PlaySound(const std::string& path)`| Работает на базе winmm. производит звуки в консоли. прикольная вещь. принимает только путь который пишется через RAW. | Если вы сделаете звук когда программа должна будет завериштся. то звук не проиграется. чтобы он проигрался `добавьте sleep_for(5000);` |
